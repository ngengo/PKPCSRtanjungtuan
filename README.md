> *"It's amazing just how much HTML, CSS and JavaScript can do. The possibilities are infinite."*

**Live site → [ngengo.github.io/PKPCSRtanjungtuan](https://ngengo.github.io/PKPCSRtanjungtuan/)**

---

## 📌 About

This interactive map was built as part of a **volunteer programme** at Tanjung Tuan, Port Dickson. The goal was to take a hand-drawn map diagram with legends — provided by a senior team member — and transform it into a fully digital, interactive experience accessible to the public.

It was my **first web development project**, built from scratch with no prior experience in frontend development. My senior had faith in me to take it on, and that trust became the motivation to see it through.

The project reignited a genuine interest in geospatial coding — maps, coordinates, latitude/longitude, and how much storytelling can be packed into a single webpage.

**Duration:** 1 month

---

## ✨ Features

| Feature | Description |
|---|---|
| 🏛 **Landmark Markers** | Clickable icons for heritage sites with photo popups |
| 🔍 **Category Filters** | Filter by Landmarks, Trails, Wildlife, Water, or Camp |
| 📖 **Info Popups** | Each landmark shows a photo, name, and description on click |
| 📜 **Legend Panel** | Toggle-able legend explaining all map icons |
| 💡 **Did You Know?** | Rotating facts about Tanjung Tuan at the bottom of the map |
| 🌿 **Landing Overlay** | Full-screen intro with a random fun fact before entering the map |
| 🔎 **Auto Zoom** | Map automatically fits all markers in view on load |
| 📐 **Responsive Icons** | Icon sizes scale dynamically as you zoom in and out |

## 🛠️ Built With

- **HTML5** — Page structure
- **CSS3** — Styling and animations
- **JavaScript (Vanilla)** — Map logic, filters, popups, and interactions
- **[Leaflet.js](https://leafletjs.com/)** — Interactive map library
- **[OpenStreetMap](https://www.openstreetmap.org/)** — Map tile provider

No frameworks. No build tools. Pure HTML, CSS, and JS.

## 🗺️ What's on the Map

**Heritage & Landmarks**
- Rumah Api Tanjung Tuan *(oldest lighthouse in Malaysia, 1817)*
- Tapak Kaki Hang Tuah *(legendary footprint on the beach)*
- Perigi Keramat *(the Mystical Well)*
- Perigi Belanda *(Dutch colonial well)*
- Bukit Batu Putih *(limestone peak with panoramic views)*

**Trails & Nature**
- Monkey Bay *(hidden beach via jungle trail)*
- Gua Bawah Rumah Api *(cave beneath the lighthouse)*
- Pulau Intan & Pulau Masjid *(coastal spots for hiking and birdwatching)*

**Wildlife & Environment**
- Raptor migration paths
- Mangrove zones
- Otter and monkey habitats
- Marine and seabird spotting areas

## 🚀 Getting Started

To run locally, simply clone the repo and open `index.html` in a browser — no server or install needed.

```bash

cd PKPCSRtanjungtuan
# Open index.html in your browser
```
